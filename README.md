**🟡 Pac-Man Developer Portfolio 👾**

A retro arcade-inspired developer portfolio built with HTML5 and CSS3. Inspired by the classic Pac-Man game, this project turns a traditional portfolio into a fun, game-like experience.

**🎮 About the Project**

This portfolio combines my interest in web development and retro gaming. Instead of a regular portfolio layout, it uses arcade-inspired elements such as score displays, levels, collectibles, and maze-style visuals to present my profile, skills, and projects.

The goal was to create a portfolio that is visually engaging while keeping the code beginner-friendly.

**✨ Features**

🟡 Player Profile — Introduction and developer information.

🕹️ Arcade HUD — Retro score and game-inspired interface.

📊 Skill Levels — Skills presented in a game-style format.

🏆 Collectibles — Achievement-inspired badges.

🎯 Project Levels — Projects displayed as arcade-style cards.

🔵 Maze-Inspired Design — Classic arcade colors and borders.

📱 Responsive Layout — Designed to adapt to different screen sizes.

**🛠️ Tech Stack**

HTML5 — Website structure and content.

CSS3 — Styling, layout, colors, and visual effects.
